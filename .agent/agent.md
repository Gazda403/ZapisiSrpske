# ЗАПИСИ СРПСКЕ - Дигитална ризница књижевног насљеђа Републике Српске

## О Пројекту
Онлајн архив књижевника из Републике Српске и Босне и Херцеговине.
Пројекат је реализован уз подршку и финансирање Министарства културе Републике Србије.

## Архитектура и Стек
- Next.js (App Router, Static Generation)
- React, Tailwind CSS
- GSAP + ScrollTrigger, Lenis smooth scroll
- Локални подаци у `/content/writers/*.json`
- Ћирилица / латиница транслитерација са конзистентним рендером
- Строга Anti-AI-slop правила
